Detection Signals
NACp Navigation Accuracy Category ≤ {{ nacp_threshold }} — the aircraft reports degraded GPS position accuracy. From TC=29 / TC=31 status messages (ADS-B version 1/2).
NIC Navigation Integrity Category ≤ {{ nic_threshold }} — the aircraft reports a large containment radius (Rc ≥ 0.3 NM). Derived from the type code of every airborne-position message.
Freeze Own ADS-B position messages keep arriving but the coordinates stay identical for ≥3 sweeps while groundspeed > 50 kt — GPS output is stuck.
Gap Aircraft still transmitting ADS-B, but no position from any source (own ADS-B or MLAT) for ≥45 s — GPS dropped out and MLAT is not covering.
ADS-B Aircraft still transmitting ADS-B, but no own position for ≥45 s while MLAT keeps updating its position — GPS dropped out, MLAT covering. Common at EFHK during GPS jamming.
SEV Severe — the position is unusable (live list: red callsign): NACp 0 (accuracy unknown), NIC 0 (no integrity) or no own ADS-B position at all (Gap / ADS-B). Everything else (NACp / NIC 1–6, Freeze) is milder degradation.
SPF Spoofing indicators — a false position does not always lower NACp / NIC, so these are recorded separately (not counted as events): own ADS-B position > 2 NM from the MLAT position (beyond the distance flown, on two consecutive comparisons; MLAT covers mainly higher altitudes); GNSS − baro altitude difference at its limit (> 3 137 ft) or jumping ≥ 500 ft; position jump faster than the aircraft can fly, confirmed by the next position. A flag raised while the aircraft reports normal GPS quality (NACp ≥ 7, no degradation signal) is the strong spoofing case (yellow); flags during jamming (NACp 0) are more often the receiver re-acquiring. First thresholds — to be tuned with data.
All signals count only aircraft heard by this receiver. NACp: 0 = unknown · 1–3 = poor (>10 NM) · 4–6 = moderate (0.1–10 NM) · 7–11 = excellent (<0.1 NM). NIC: 8 = Rc <0.1 NM · 7 = <0.2 NM · 6 = 0.3–0.6 NM · ≤5 = ≥1 NM · 0 = unknown.
